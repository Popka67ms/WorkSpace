Что делает код: Считает, сколько всего раз заданная цифра digit встречается во всех числах массива nums.

Как решал: Прохожу циклом по массиву, беру каждое число и разбираю его по цифрам во внутреннем цикле while. Через num % 10 забираю последнюю цифру: если она совпадает с нужной — увеличиваю счётчик count, затем через num / 10 отбрасываю её. Когда все числа разобраны, возвращаю итоговый результат.
