Что делает код: Генерирует и возвращает вообще все возможные варианты перестановок чисел из переданного массива в виде списка массивов.

Как решал: Использовал стандартные алгоритмы из библиотеки <algorithm>. Сначала отсортировал массив через sort, чтобы начать с самой первой лексикографической перестановки. Затем запустил цикл do-while со встроенной функцией next_permutation, которая на каждом шаге переставляет элементы к следующей комбинации и сохраняет её в итоговый массив, пока перестановки не закончатся.
