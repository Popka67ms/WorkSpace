
Что делает код: Считает суммарный «вес» строки по правилу из условия: берет обратный номер каждой буквы в алфавите (a = 26, b = 25 ... z = 1), умножает его на порядковый номер буквы в строке (с 1) и складывает всё вместе.

Как решал: Запустил обычный цикл по строке от 0 до конца. Позицию буквы с конца алфавита нахожу через формулу 26 - (s[i] - 'a'), а индекс символа беру как i + 1. На каждом шаге перемножаю их, прибавляю к общей сумме и в конце её возвращаю.
