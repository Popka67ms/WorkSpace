Что делает код: Генерирует первые numRows строк треугольника Паскаля в виде двумерного массива, где каждая строка начинается и заканчивается на 1, а числа внутри равны сумме двух чисел над ними.

Как решал: Иду циклом по строкам от 0 до numRows - 1. На каждом шаге создаю новую строку нужной длины i + 1, сразу заполнив её единицами (чтобы края не трогать). Затем вторым циклом прохожу по элементам внутри строки и считаю каждое значение как сумму двух чисел из предыдущей строки: слева сверху и прямо сверху. В конце возвращаю готовый массив.
